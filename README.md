# Mithai Store Website

## Project Overview
Mithai Store is a responsive e-commerce website developed using HTML, CSS, and JavaScript. The application fetches data through API integration and displays different sweet products with a clean user interface. Users can browse sweets, add products to the cart, update quantities, and view the total amount dynamically.

## Features

- API integration
- Responsive user interface
- Sweet products display
- Add to Cart functionality
- Increase quantity (+)
- Decrease quantity (-)
- Remove items from cart
- Dynamic cart count update
- Dynamic total price calculation
- Error handling
- Simple and clean design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API

## Website Functionalities

### Product Section
- Displays sweet products with images
- Shows product names and prices
- Add To Cart functionality

### Cart Section
- Displays added products
- Quantity controls:
  - "+" button increases quantity
  - "-" button decreases quantity
- Remove button deletes products
- Updates cart item count dynamically
- Calculates total amount automatically

## Error Handling

- Handles API fetch errors
- Displays error messages if loading fails
